## 📋 Overview

**Lumora Digital** is a professional, fully-featured website built for digital agencies, freelancers, and creative businesses. Featuring modern HTML5, CSS3, and Vanilla JavaScript with smooth animations, responsive design, and interactive functionality.

### ✨ Key Highlights

- ✅ **100% Responsive Design** - Works flawlessly on all devices
- ✅ **Smooth Animations** - CSS + Canvas particle effects
- ✅ **8 Professional Pages** - Complete website structure
- ✅ **Form Validation** - Real-time email/phone validation
- ✅ **Portfolio Filtering** - Interactive project showcase
- ✅ **Modern UI/UX** - Clean, professional design
- ✅ **Zero Dependencies** - Pure HTML, CSS, JavaScript
- ✅ **SEO Friendly** - Semantic markup ready

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/aryansankpal206-star/lumora-digital.git
cd lumora-digital
```

### Run Locally

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js
npx http-server
```

Then open `http://localhost:8000` in your browser.

## 🔧 Customization

### Change Colors

Edit CSS variables in `css/style.css`:

```css
:root {
    --primary-color: #6366f1;
    --accent-color: #ec4899;
    /* ... more colors ... */
}
```

### Update Content

Simply edit the HTML files:

```html
<h1>Your Title Here</h1>
<p>Your content here</p>
```

### Add Images

1. Place images in `images/` folder
2. Update image paths in HTML:

```html
<img src="images/your-image.jpg" alt="Description">
```

## 🐛 Troubleshooting

**Styles not loading?**
- Clear browser cache (Ctrl+Shift+Del)
- Check file paths in HTML

**Mobile menu not working?**
- Check browser console for errors
- Verify hamburger icon displays on mobile

**Form not submitting?**
- Update Formspree ID in `js/form.js`
- Or integrate your own backend
